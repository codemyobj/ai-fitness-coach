这一步做了什么

  • 勾选一组就自动开始倒计时，不用手动点「开始休息」
  • 按时间戳倒计时：切后台、锁屏、掉帧回来剩余秒数依然准（不是每秒累减）
  • 归零 → 双震提示 + 绿色「休息结束」态，6 秒后自动收起
  • 点数字 = 暂停/继续；−15s / +15s 只改本次；「跳过」立即收起
  • 进度条下面一行告诉你接下来练什么（下一组 / 下一个动作）
  • 今天的最后一个动作做完不再休息；取消勾选也不会误触发
  • 跟练页会短暂保持屏幕常亮，离开页面自动失效

默认时长在哪改

我的 → 组间休息 → 30 / 45 / 60 / 90 / 120 秒，或关闭自动休息。存本地 storage，不占云数据库、不用重新部署。

没做的

没做「休息结束音效」——加音频文件会增加包体积（分包已 1.21MB / 2MB），用震动 + 视觉代替。

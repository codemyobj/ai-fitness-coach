用户协议
隐私政策
一、服务说明与协议接受
1.1 轻练打卡健身（以下简称「本小程序」）是一款由个人开发者独立开发并运营的健身训练记录与指导工具，为你提供运动档案建立、训练计划生成、动作示范、训练打卡与数据统计等功能。
1.2 你开始使用本小程序，或在建档流程中勾选同意本协议，即表示你已阅读、理解并同意本协议全部内容。若你不同意，请停止使用。
1.3 若你未满 18 周岁，请在监护人陪同下阅读本协议，并在取得监护人同意后使用。
二、账号与登录
2.1 本小程序通过微信授权静默登录，无需单独注册账号，也不会获取你的手机号。
2.2 你的训练进度、训练计划等数据与微信账号绑定。删除或更换微信账号将无法继续访问原数据。
2.3 请勿将账号交由他人使用。因账号被他人使用产生的后果由你自行承担。
三、你的行为规范
3.1 你承诺不利用本小程序从事任何违反法律法规、公序良俗的行为。
3.2 你不得使用自动化脚本、批量工具等方式异常访问或抓取本小程序的数据与内容，不得对服务进行反向工程、攻击或干扰。
3.3 你填写或记录的内容由你负责，不得包含违法违规、侵权或他人的隐私信息。
四、健康与安全提示（请务必阅读）
4.1 本小程序提供的训练计划、动作示范与数据统计均属一般健身参考信息，不构成医疗建议、诊断或治疗方案。
4.2 开始任何训练计划前，建议你先咨询医生或专业教练，尤其是存在心血管疾病、关节损伤、孕期或其他病史的情况。
4.3 训练过程中请根据自身感受调整强度。若出现疼痛、眩晕、胸闷、呼吸急促等不适，请立即停止训练并及时就医。
4.4 你应在安全的环境中使用合适的器械进行训练。因未按动作要点训练、未评估自身健康状况或擅自增加强度而造成的身体损伤，责任由你自行承担。
五、训练计划的性质与使用建议
5.1 训练计划由本小程序依据你填写的档案，通过开发者预设的确定性规则自动编排生成（动作池按可用器械筛选、按训练目标安排分化、按周推进容量与强度），不涉及人工智能生成合成技术；计划内容仍可能存在不适合你个人情况的部分。
5.2 你应结合自身实际情况判断计划是否合适，并可在训练过程中自行调整组数、次数与重量。
5.3 训练计划与训练建议仅供参考，不代表开发者对训练效果作出任何承诺或保证。
六、知识产权与第三方素材
6.1 本小程序的界面设计、程序代码、文案内容的知识产权归开发者所有。
6.2 动作数据与示范图片来源于第三方素材提供方 RepDB（repdb.co），按其免费档许可证使用，并在「我的」页保留了必要署名。相关权利归原权利人所有。
6.3 未经书面许可，你不得复制、传播、出售本小程序的任何内容或将其用于商业用途。
七、服务变更、中断与终止

用户协议
隐私政策
一、引言与适用范围
1.1 本政策适用于轻练打卡健身小程序。我们深知个人信息对你的重要性，并会按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》等法律法规的要求处理你的个人信息。
1.2 本政策仅适用于本小程序。若你通过本小程序跳转到第三方服务，请另行阅读该第三方的隐私政策。
1.3 你开始使用本小程序，即表示你已同意我们按照本政策处理你的个人信息。你可以在「我的 → 清空训练数据」中删除已产生的数据，或通过关闭订阅提醒、不再授权等方式撤回同意。
二、我们收集哪些信息
我们遵循「最小必要」原则，只收集实现功能所必需的信息。下表列出了全部收集项，其中标注为「必需」的信息是提供核心功能所必需的，拒绝提供将无法使用对应功能；标注为「可选」的信息仅在你主动提供时才会收集，你可以随时不提供或撤回。
除下表列出的信息外，本小程序不会收集你的手机号、通讯录、位置、相册、麦克风、剪贴板或设备标识等任何其他个人信息。
微信标识（OpenID） 必需
内容微信登录返回的用户唯一标识，不含昵称、头像、手机号
用途识别你的账号，把你的训练数据与账号关联
身体档案 必需
内容性别、年龄、身高、体重、训练目标、训练经验、可用器械、每周训练天数
用途计算训练强度、生成个性化训练计划
训练记录 必需
内容打卡日期、训练时长、完成动作、组数、次数、重量，以及由此估算的消耗
用途生成数据看板、连续打卡统计与周目标进度
身体记录 可选
内容记录日期、体重、体脂率、备注
用途记录并展示你的身体变化趋势
头像与昵称 可选
内容你主动选择的微信头像、填写的昵称
用途仅在「我的」页展示，仅你本人可见
订阅消息授权 可选
内容你授权的订阅消息额度（每次授权对应一条提醒）
用途在你设定的时间发送训练提醒
本地设置数据 可选
内容重量单位、组间休息时长、动作收藏、协议同意记录
用途记住你的使用偏好
三、我们如何使用这些信息
3.1 用于向你提供核心功能：按你的档案编排训练计划、展示动作示范、记录训练打卡、统计训练数据与身体变化趋势。
3.2 用于改善使用体验：记住你的单位偏好、组间休息时长与动作收藏。
3.3 用于向你发送训练提醒：仅在你主动授权订阅消息后，按你设定的时间发送。
3.4 我们不会将你的个人信息用于广告推送、用户画像或与上述目的无关的任何用途。
四、信息的存储与安全
4.1 存储位置：你的档案、训练记录与身体记录保存在微信云开发（腾讯云）为开发者提供的云数据库中，服务器位于中国境内。你的偏好设置与协议同意记录保存在你自己的手机本地。
4.2 传输安全：数据通过微信提供的加密通道传输。
4.3 访问控制：云数据库按用户维度隔离，你只能读写自己的数据，其他用户无法访问。
4.4 保存期限：在你使用本小程序期间持续保存。你可以随时通过「我的 → 清空训练数据」删除训练打卡、身体记录与训练计划；清除后不可恢复。
4.5 需要说明的是，运动档案与身体记录属于个人健康相关信息，属于敏感个人信息范畴。请你确认在知情的前提下自愿提供。
五、信息的共享、转让与公开披露
5.1 我们不会出售你的个人信息，也不会与任何第三方共享，但以下情形除外：
（1）已取得你的明确同意；
（2）根据法律法规、司法或行政机关的强制性要求必须提供；
（3）为维护公共利益或你本人的人身、财产安全所必需。
5.2 本小程序不会将你的个人信息用于任何用户间的展示、排行或社交功能，你的数据仅你本人可见。
六、第三方服务
6.1 微信云开发：用于数据存储，由腾讯公司提供，遵循微信相关的隐私保护规则。
6.2 微信订阅消息：用于发送训练提醒，仅在你主动授权后生效。
6.3 动作数据与示范图片：来自素材提供方 RepDB（repdb.co），该素材不含任何用户个人信息。
6.4 本小程序未接入任何第三方广告、统计或数据分析 SDK。
七、你的权利
7.1 查询与更正：你可在「我的 → 编辑身体档案」中查看并修改全部档案信息。
7.2 删除：你可在「我的 → 清空训练数据」中一次性删除云端的训练打卡、身体记录与训练计划。
7.3 撤回同意：你可随时在「我的 → 训练提醒」中关闭提醒，或在头像昵称编辑弹层中恢复默认头像，以撤回对应授权。
7.4 注销：如你希望删除全部数据并停止使用，可先清空训练数据，再移除本小程序，并通过本政策「十、联系我们」中的方式告知我们。
7.5 投诉与举报：若你认为我们处理个人信息的行为侵害了你的合法权益，可通过本政策「十、联系我们」中的方式反馈，我们会在收到后尽快处理。
八、未成年人保护
8.1 本小程序主要面向成年人。若你未满 18 周岁，请在监护人指导下使用，并由监护人代为阅读并同意本政策。
8.2 若我们发现在未事先取得监护人同意的情况下收集了未成年人的个人信息，会尽快予以删除。
九、政策的更新
9.1 当收集范围、使用目的或存储方式发生实质变化时，我们会更新本政策并提升版本号，同时在本小程序内重新提示你阅读确认。
9.2 本政策的版本号与生效日期展示在本页顶部，你可以随时查阅。
十、联系我们
10.1 如你对本政策或你的个人信息有任何疑问、意见或投诉，可通过以下方式联系开发者：GitHub：github.com/codemyobj。
10.2 一般情况下，我们会在收到你的反馈后尽快答复处理。

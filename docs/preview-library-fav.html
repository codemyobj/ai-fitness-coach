交互说明

  • 收藏入口：搜索框下方「♡ 我的收藏 + 数量」，点一下只看收藏，再点回到全部
  • 卡片右侧 ♡ / ♥：用 catchtap 阻止冒泡，点收藏不会打开详情
  • 收藏顺序：最近收藏的排最前；在收藏页取消 ♥，卡片立即消失
  • 入口打通：「我的 → ♥ 我的收藏（带数量）」直接跳 library?fav=1
  • 空态：没有收藏时给引导 + 「看全部动作」按钮

实现要点

  • 新服务 services/favorites.js：存在 wx.storage（key fav_exercises_v1），不碰云数据库
  • 脏数据容错：非数组 / 非字符串 / 空串 / 重复 → 过滤；上限 200 条
  • 存储读写包了 try/catch：写满或权限异常不会让页面崩
  • 收藏 id 在动作库里查不到时（比如素材换源）自动过滤，不出现空白卡片
  • 单测 test-library.js 45 → 66 项，覆盖 toggle / 顺序 / 去重 / 上限 / 脏数据 / 与动作库联动
